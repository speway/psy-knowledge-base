# Академическая база знаний кафедры психологии · Филиал МГУ в г. Ташкенте

> **Психология МГУ · Ташкент** (MSU Psychology Tashkent Academic Portal)  
> Официальная платформа оцифровки учебных дисциплин, хрестоматий, семинарских планов и академических профилей профессорско-преподавательского состава.

---

## 🏛️ О проекте
Академический портал разработан специально для факультета психологии Филиала Московского государственного университета имени М.В. Ломоносова в городе Ташкенте в строгом университетском стиле.

### 🌟 Ключевые разделы
1. **Кафедра и научные профили преподавателей**:
   - Флагманский профиль старшего преподавателя **Туниянц Анны Александровны** (стаж в Ташкентском филиале МГУ с 2011 года).
   - Прямая интеграция с системой **«ИСТИНА МГУ»** (Истина ID: `10554505`).
   - 11 направлений исследований, научные труды в «Вестнике Московского университета. Серия 14. Психология», перечень тем ВКР и курсовых работ.
   - Масштабируемая структура кафедры для добавления всех преподавателей филиала.

2. **Каталог дисциплин и пошаговый навигатор семинаров**:
   - Флагманский оцифрованный курс **«Психология мотивации и эмоций»** (1 курс бакалавриата, 34 акад. часа, экзамен).
   - 9 семинаров в структурированном виде: вопросы для подготовки, первоисточники с прямой кнопкой чтения, методические советы лектора.

3. **Читальный зал первоисточников (Digital Reader)**:
   - 19 оцифрованных книг и статей (Д.А. Леонтьев, З. Фрейд, А.Н. Леонтьев, Х. Хекхаузен, В.К. Вилюнас, Т.Ю. Базаров, Ю.Б. Гиппенрейтер и др.).
   - Постраничное чтение, регулировка шрифта, копирование библиографической ссылки по ГОСТ 7.0.5–2008 в один клик.

4. **Мини-уголок научного лексикона**:
   - 280 верифицированных психологических терминов по 9 научным категориям.
   - Ежедневный виджет **«Термин дня»** и генератор случайного термина.
   - Мгновенный поиск и алфавитный указатель (А–Я).

5. **Студенческий научный гид**:
   - Алгоритм выбора научного руководителя и закрепления тем ВКР.
   - Каноническая структура введения (актуальность, объект, предмет, гипотеза, задачи, методы).
   - Памятка по оформлению списка литературы по ГОСТ.

## 📱 Мобильная оптимизация
- Полная адаптивность под любые экраны (Mobile-first).
- Фиксированная нижняя навигационная панель (Bottom Bar) для комфортного взаимодействия одной рукой на смартфонах.
